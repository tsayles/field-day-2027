# Table Leveling Blocks

Shims and leveling blocks needed to stabilize tables across uneven terrain at Fort Flagler.

## Problem

Fort Flagler's terrain is uneven, making it difficult to set up level work surfaces with standard 6' folding tables. Tables at operating stations need to be stable and level for:
- Equipment placement
- Safe operator work surfaces
- Secure cable routing
- Preventing equipment from sliding or tipping

## Solution: Leveling Blocks/Shims

Adjustable leveling blocks or shims under table legs can:
- Accommodate ground slope and irregularities
- Provide fast, repeatable leveling for rapid setup/teardown
- Work with existing [Costco-style 6' folding tables](../shared/tables.md)
