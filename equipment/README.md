# Equipment Information

This directory organizes Field Day 2027 equipment by **location** across all stations and sites.

## Organizational Scheme

Equipment is organized into folders corresponding to physical locations at Fort Flagler:

### 2026 Stations (Radio Operations)

| Folder | Station | Band / Mode | Location |
|--------|---------|-------------|----------|
| `15m/` | Station 1 | 15m — Phone | Bluff (Battery Grattan) |
| `20m/` | Station 3 | 20m — Phone | Bluff (Battery Grattan) |
| `40m/` | Station 4 | 40m — Phone | Bluff (Battery Grattan) |
| `cw-beach/` | Station 2 | CW Beach — all CW bands | CW Beach |
| `digital/` | Station 5 | Digital (any band) | Bluff (Battery Grattan) |
| `gota/` | Station 6 | GOTA — Get On The Air | Bluff (Battery Grattan) |
| `satellite/` | Station 7 | Satellite | Bluff (Battery Grattan) |

### Other Locations

| Folder | Description |
|--------|-------------|
| `bluff/` | Bluff (Battery Grattan) — Base of operations; shared equipment and resources |
| `visitor-tent/` | Visitor Tent — located at Bluff |
| `wagon-wheel/` | Wagon Wheel — Group campsite; Radio Camp base, Friday potluck |
| `wish-list/` | Wish list — Future equipment and upgrades |

## Usage

Each location folder contains a README.md with details about:
- Equipment inventory and specifications
- Setup and teardown notes
- Operating procedures
- Historical notes and lessons learned
