# Wagon Wheel

Group campsite location for Field Day 2027. Wagon Wheel hosts Radio Camp activities (June 21-24) and the Friday potluck gathering.

## Site Information

**Location:** Fort Flagler State Park, Marrowstone Island  
**Purpose:** Radio Camp base and group gathering space  
**Events:** Radio Camp (Wed-Fri before Field Day), Friday potluck  

## Facilities

### [Rented Portable Facilities](../shared/portable-facilities.md)
Rented portable toilets and portable sink for Radio Camp participants and Field Day volunteers sanitation facilities (shared across Bluff, CW Beach, Wagon Wheel).
