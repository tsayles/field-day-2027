# Tower Trailer

The tower trailer is a critical piece of infrastructure for Field Day operations. It transports and stores all tower segments, antenna components, and large beam antennas used across multiple stations.

## Trailer Specifications

**Type:** Equipment trailer with jack-style landing gear  
**Landing Gear:** Trailer jack style (requires cribbing for stabilization)

### Cargo Capacity

The tower trailer transports:
- Crank-up tower (15m station primary antenna support)
- Rohn tower segments (20m station, ~4 sections)
- Large beam antennas for multiple stations
- Antenna mounting hardware and accessories
- Support equipment and tools

## Setup Space Requirements

**Critical:** 15'+ of flat, clear space is required **behind the trailer** for safe and comfortable antenna mounting/unmounting operations.

This space is needed for:
- Laying out antenna elements and components
- Assembling tower sections
- Maneuvering antenna assembly into position
- Safe work area for team members

## Landing Gear & Cribbing

The trailer uses **jack-style landing gear** that requires **cribbing** for proper stabilization:
- Inspect cribbing blocks before each deployment
- Verify blocks are under all landing gear points
- Check for proper weight distribution
- Ensure stable, level support before beginning work
- Use quality cribbing materials (pressure-treated wood, minimum)
