# Tents

Multi-room pop-up tents used for shelter at operating stations.

## CORE Instant Cabin Tent

**Product:** CORE Instant Cabin Tent | Multi Room Portable Pop Up Tent  
**Capacity:** Sleeps 9 people  
**Dimensions:** 14' x 9'  
**Rooms:** 3-room configuration  
**Setup Time:** 2 minutes  

### Notes
- Used across multiple stations for weather protection and operator comfort
- Quick setup allows efficient station teardown
- Portable design facilitates rapid relocation if needed

### Maintenance
- Store in dry location between events
- Check zippers and seams before each deployment
- Inspect poles for damage or bending
