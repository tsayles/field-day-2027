## Shared Usage

The rotator system is shared by:
- **15m Phone Station** — 15m Phone antenna on crank-up tower
- **20m Phone Station** — 20m antenna on Rohn tower segments

## Installation & Maintenance

- Verify mounting hardware is secure before each deployment
- Inspect rotator bearings and lubrication
- Check control cables for damage, corrosion, or broken conductors
- Test rotation function and indicator accuracy
- Verify control box operation and display readings
- Store in protected location between events
- Keep controller dry and protected from weather
