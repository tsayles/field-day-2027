## Workflow

1. **Capture** — Add raw notes, transcripts, and observations right after FD.
2. **Triage** — Convert observations into tracked action items in `todos/`.
3. **Resolve** — Work items off the todo lists through the year.
4. **Report** — Summarize outcomes and carry forward unresolved items.
