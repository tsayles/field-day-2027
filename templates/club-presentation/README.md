# Mike & Key Amateur Radio Club presentation template

Use this template to make slides for a club meeting, Field Day update, or
technical talk. Both files work in
[LibreOffice Impress](https://www.libreoffice.org/download/download-libreoffice/);
you don't need Microsoft 365.

| File | When to use it |
| --- | --- |
| [Download the template (.otp)](mk-club-presentation-template.otp?raw=true) | Start your own presentation with editable starter slides and club branding. |
| [Download the example (.odp)](mk-club-presentation-example.odp?raw=true) | See how the layouts work in practice. The comparison and prices are illustrative. |

## Make your own presentation

1. Download and open the `.otp` template in Impress to start a new presentation.
   Save it as an `.odp` file with your own filename.
2. Replace the title, presenter name or callsign, and date. Duplicate the layouts
   you need and delete any unused starter slides.
3. Replace sample text and update source lines with your references and image
   credits. Check the speaker notes for editing tips, then remove or replace
   the sample notes before sharing the editable deck.
4. Save the `.odp` for future edits. To share with people who don't use Impress,
   choose **File > Export As > Export as PDF**.

## What's included

The template and example each have eight starter layouts: title, section divider,
bullet points, image with explanation, side-by-side comparison, cost analysis,
workflow diagram, and closing or references. The title, section, and content
master slides control shared formatting; use **View > Master Slide** to edit
them. The table and diagram are editable in Impress, and the diagram connectors
stay attached when you move the boxes.
