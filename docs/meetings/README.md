# Field Day 2027 Committee Meetings

This folder tracks sprint planning and scrum sessions for Field Day 2027.
We use an agile sprint model to organize work into 4–6 week cycles, with each
meeting serving as a scrum standup/sprint review hybrid. Committee meetings
run 1st and 3rd Wednesdays at 8 PM PT, November 2026 through July 2027.

**Note on Sprints:** Sprints are intentionally 4–6 weeks long (not 2 weeks) to 
accommodate part-time volunteer schedules. Most work items span multiple sprints.

## Meeting Structure (Scrum Model)

Each meeting follows a standard scrum format:

1. **Sprint Review** (10 min) — Review completed tasks from previous sprint
2. **Backlog Grooming** (20 min) — Discuss upcoming sprint work, refine issues
3. **Sprint Planning** (15 min) — Assign work, set sprint goals
4. **Open Discussion** (15 min) — Questions, blockers, dependencies
5. **Decisions & Commitments** (5 min) — Confirm who's doing what, next steps

**Target meeting duration: 60 minutes**

## Folder Structure

Each meeting gets its own file:

```
docs/meetings/
  YYYY-MM-DD-meeting-agenda.md   # agenda for upcoming meeting (created by Sprint Lead)
  YYYY-MM-DD-meeting-notes.md    # notes from completed meeting (created by Secretary)
```

Use `templates/meeting-agenda-template.md` and
`templates/meeting-notes-template.md` as starting points.

## Working with GitHub Issues

- Each sprint should have a GitHub issue or project milestone tracking work
- Assign issues to volunteers; link to project board
- Use issue labels: `sprint-1`, `sprint-2`, etc. for sprint assignment
- Use labels: `needs-triage`, `high-priority`, `question`, `blocker` for status
- Close issues when sprint work is complete; move to next sprint if needed
