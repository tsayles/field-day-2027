# Field Day 2027 Committee Meetings

This folder tracks committee meeting agendas and notes for Field Day 2027
planning. Meetings run monthly from November 2026 through May 2027, then
bi-weekly in June leading up to Field Day (last full weekend of June 2027).

## Proposed Schedule

| # | Date | Focus |
|---|------|-------|
| 1 | Nov 2026 | Kickoff — roles, site, master action items |
| 2 | Dec 2026 | Site confirmation, equipment inventory |
| 3 | Jan 2027 | Logging software, network plan |
| 4 | Feb 2027 | Training plan, CW practice schedule |
| 5 | Mar 2027 | GOTA, digital station, bonus checklist |
| 6 | Apr 2027 | Operating schedule, volunteer signup |
| 7 | May 2027 | Dry run debrief, final logistics |
| 8 | Jun (early) 2027 | Final checklist review |
| 9 | Jun (mid) 2027 | Pre-event walkthrough |

## Folder Structure

Each meeting gets its own file:

```
docs/meetings/
  YYYY-MM-DD-meeting-notes.md   # notes from a completed meeting
  YYYY-MM-DD-agenda.md          # agenda for an upcoming meeting
```

Use `templates/meeting-agenda-template.md` and
`templates/meeting-notes-template.md` as starting points.
